## Explore Escher Tessellation

Escher Tessellation lets you investigate repeating geometric designs directly in a web browser. Its canvas renderer produces patterns based on triangular, square, hexagonal, and combined triangle-hexagon layouts.

Built for artists, designers, educators, and visual experimentation, the tool provides live control over tile dimensions. Multiple color themes and an optional rotating mode also make it possible to compare still compositions with animated variations.
